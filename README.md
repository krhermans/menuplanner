# Mijn Menuplanner

Weekmenu van zaterdag tot vrijdag, met gerechtenbibliotheek, menu picker en boodschappenlijst.

- Werkt offline na het eerste bezoek.
- Synchroniseert tussen pc, iPhone en iPad via je eigen Google-script (zie **HANDLEIDING-SYNC.md**). Zonder sync staan de gegevens alleen op het toestel.
- Maak geregeld een back-up via **Onderdelen → Back-up downloaden**.
