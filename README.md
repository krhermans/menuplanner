# Mijn Menuplanner

Weekmenu van zaterdag tot vrijdag, met gerechtenbibliotheek, menu picker en boodschappenlijst.

- Werkt offline na het eerste bezoek.
- Gegevens staan alleen op het toestel (in de browser). Maak geregeld een back-up via **Onderdelen → Back-up downloaden**.
- Je gerechten staan niet in deze repository. Zet ze op je toestel via **Onderdelen → Back-up terugzetten**.
